# 棱镜回响 PRISM ECHO

3D Roguelike 塔防游戏 · Three.js 纯前端实现 · 零构建 / 零依赖

## 怎么运行

**方式一（推荐，双击即玩）**：解压后直接双击 `index.html`。
Three.js 已内置于 `vendor/`，无需联网、无需服务器、无需安装任何东西。

**方式二（本地服务器）**：

```bash
cd prism-echo
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 这是一个什么样的塔防

它不是「塔各自开火」的常规塔防。核心机制是 **光束折射**：

> 星核（基地）持续发射一道高能光束——但它自己不会瞄准。
> 光束总是射向最近的棱镜塔，被折射后再射向下一个棱镜，
> 由此织出一张贯穿战场的 **伤害光路**。
> **棱镜摆在哪里，光就烧穿哪里。**

围绕这个核心，再叠加两层 Roguelike 随机构筑：

1. **每局随机地图** —— 入口、蜿蜒路径、能量格（建造 6 折）、岩石（禁建）全部程序化生成；
2. **每波肃清后三选一「回响」遗物** —— 18 种遗物（分光棱镜 / 超导腔 / 处决协议……）一次性获取、本局永久生效，配合三系塔（棱镜 / 霜塔 / 脉冲炮）形成每局不同的构筑答案。

15 波攻防，守住星核即胜利；通关后可挑战无尽模式。死亡即重开——新地图、新构筑（ Roguelike 永久死亡）。

## 操作

| 操作 | 效果 |
|---|---|
| 左键点击 | 建造（先点底部卡片选塔）/ 选中已有塔 |
| 按住拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| Shift + 点击 | 连续建造 |
| 1 / 2 / 3 | 快速选择三种塔 |
| Space | 立即开始下一波 |
| Esc | 取消选择 / 建造模式 |

## 数值小抄

- 三系塔：**◈ 棱镜**（折射光束，增益 ×1.15→1.58）· **❄ 霜塔**（范围减速 30%→50%）· **✦ 脉冲炮**（单体弹丸）
- 光束：初始 4 段折射链，每段衰减 12%；棱镜可反向增幅
- 敌人六种：蜂群 / 游袭者 / 重装体 / **偏导体（光束抗性 55%）** / 裂生体（死亡分裂）/ 湮灭核心（Boss）
- 击杀 + 波次奖励 + 遗物利息 = 经济循环；漏怪扣星核，归零即败

## 文件结构（多文件架构）

```
prism-echo/
├── index.html          # 入口 + DOM 骨架（script 按依赖顺序加载）
├── style.css           # 深空霓虹风 UI
├── README.md
├── vendor/
│   └── three.min.js    # Three.js r128（本地化，离线可玩）
└── js/                 # 全局命名空间 window.PE，14 个模块
    ├── config.js       # ① 全部数值与平衡表（想调难度改这里）
    ├── utils.js        # ② 种子随机数 / 数学 / 坐标换算
    ├── sfx.js          # ③ WebAudio 程序化音效（零资源文件）
    ├── scene.js        # ④ 渲染器 / 相机 / 灯光 / 简易轨道控制
    ├── map.js          # ⑤ 程序化地图（随机路径生成算法）
    ├── beam.js         # ⑥ ★核心机制：光束折射链系统
    ├── enemy.js        # ⑦ 敌人（六种 / 分裂 / Boss 血量档位）
    ├── tower.js        # ⑧ 三系塔 + 弹丸 + 建造幽灵
    ├── waves.js        # ⑨ 15 波剧本 + 无尽模式程序生成
    ├── relics.js       # ⑩ 18 种遗物池（Roguelike 三选一）
    ├── game.js         # ⑪ 状态机 / 经济 / 粒子特效池
    ├── input.js        # ⑫ 指针交互（建造/选中/相机）
    ├── ui.js           # ⑬ HUD / 面板 / 模态框
    └── main.js         # ⑭ 启动器与主循环
```

## 调参指南

所有平衡数值集中在 `js/config.js`：塔的三级属性、敌人血量/速度/赏金、
波次编排、光束基础伤害/衰减/链长、能量经济……改完刷新页面立即生效。
