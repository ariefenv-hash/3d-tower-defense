# 棱镜回响 · 星墨手卷 PRISM ECHO

3D Roguelike 塔防游戏 · Three.js 纯前端实现 · 零构建 / 零依赖
**玄墨为底 · 宣纸作字 · 朱砂点印 · 月金描线** —— 桌面与手机双端可玩

## 怎么运行

**方式一（推荐，双击即玩）**：解压后直接双击 `index.html`。
Three.js 已内置于 `vendor/`，无需联网、无需服务器、无需安装任何东西。

**方式二（本地服务器）**：

```bash
cd prism-echo
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**手机**：把解压目录发给手机后用浏览器打开 `index.html`（或任意静态服务器托管），
即可以触屏手势游玩（见下）。

## 这是一个什么样的塔防

它不是「塔各自开火」的常规塔防。核心机制是 **光束折射**：

> 星核（基地）持续吐出一道月金色的**高能流光**——但它不瞄、不追、不回头。
> 光束总是射向最近的棱镜塔，被折射后再射向下一个棱镜，
> 由此织出一张贯穿战场的 **伤害光路**。
> **棱镜摆在哪里，光就烧穿哪里。**

围绕这个核心，再叠加两层 Roguelike 随机构筑：

1. **每局随机星图** —— 入口、蜿蜒曲径、能量格（建造 6 折）、岩石（禁建）全部程序化生成；
2. **每波肃清后三选一「回响拾遗」** —— 18 种遗物（分光棱镜 / 超导谐振腔 / 处决协议……）一次性获取、本局永久生效，配合三系塔（棱镜 / 霜塔 / 脉冲炮）形成每局不同的构筑答案。

十五波攻防，守住星核即胜利；通关后可入「无尽长夜」。星核沉眠即重开——新星图、新构筑（Roguelike 永久死亡）。

## 双端操作

| 操作 | 桌面 | 触屏 |
|---|---|---|
| 建造 / 选中 | 左键点击（先点底部卡片选塔） | 轻点（先点底部卡片选塔） |
| 转动视角 | 按住拖拽 | 单指拖动 |
| **地图缩放** | 滚轮 | **双指捏合**，或右侧 ⊕⊖ 按钮 |
| 连续建造 | Shift + 点击 | ——（放置后自动退出建造） |
| 快速选塔 | 1 / 2 / 3 | 点卡片 |
| 立即开波 | Space | 点「启第 N 波」按钮 |
| 取消选择 | Esc | 点空白处 |
| 遗物详情 | 悬停左侧印匣 | 点按印匣展开 / 收起 |

移动端已按手机竖屏完整适配：HUD 两行紧凑排布、布防卡三列等分、
塔详情变全宽底板、三选一改横排信笺样式，底部自动避开 Home Indicator 安全区。

## 数值小抄

- 三系塔：**◈ 棱镜**（折射流光，增益 ×1.15→1.58）· **❄ 霜塔**（范围减速 30%→50%）· **✦ 脉冲炮**（单体弹丸）
- 光束：初始 4 段折射链，每段衰减 12%；棱镜可反向增幅
- 敌人六种：蜂群 / 游袭者 / 重装体 / **偏导体（光束抗性 45%）** / 裂生体（死亡分裂）/ 湮灭核心（Boss）
- 击杀 + 波次奖励 + 遗物利息 = 能量循环；漏怪扣星核，归零即败

## 文件结构（多文件架构）

```
prism-echo/
├── index.html          # 入口 + DOM 骨架（衬线字体引入 · script 按依赖顺序加载）
├── style.css           # 「星墨手卷」主题：玄墨/宣纸/朱砂/月金 + 桌面&移动端双断点
├── README.md
├── vendor/
│   └── three.min.js    # Three.js r128（本地化，离线可玩）
└── js/                 # 全局命名空间 window.PE，14 个模块
    ├── config.js       # ① 全部数值与平衡表（含塔/敌人主题配色，想调难度改这里）
    ├── utils.js        # ② 种子随机数 / 数学 / 坐标 / 触屏检测
    ├── sfx.js          # ③ WebAudio 程序化音效（零资源文件）
    ├── scene.js        # ④ 渲染器 / 相机 / 月夜灯光 / 明月与月晕
    ├── map.js          # ⑤ 程序化星图（随机曲径 / 金尘暗道 / 朱砂裂口）
    ├── beam.js         # ⑥ ★核心机制：月金光束折射链系统
    ├── enemy.js        # ⑦ 敌人（六种山海异兽 / 分裂 / Boss 血量档位）
    ├── tower.js        # ⑧ 三系塔 + 弹丸 + 建造幽灵（玉质哑光材质）
    ├── waves.js        # ⑨ 15 波剧本 + 无尽长夜程序生成
    ├── relics.js       # ⑩ 18 种遗物池（凡品/珍品/孤品 三选一）
    ├── game.js         # ⑪ 状态机 / 经济 / 粒子特效池
    ├── input.js        # ⑫ 统一指针交互（鼠标+触屏：单指转卷 / 双指捏合缩放 / 轻点布防）
    ├── ui.js           # ⑬ HUD / 竖排卷首 / 信笺卡 / 缩放按钮
    └── main.js         # ⑭ 启动器与主循环
```

## 主题定制

- **字体**：站酷小薇（题字）· 思源宋体（正文）· Cormorant Garamond（数字），由 Google Fonts 提供；
  离线时自动回退本地楷体 / 宋体，书卷气不减。
- **配色**：全部集中在 `style.css` 的 `:root` 变量（`--cinnabar` 朱砂 / `--gold` 月金 / `--paper` 宣纸 …），
  3D 场景颜色集中在 `js/config.js` 与各模块的材质定义处。
- **调参**：所有平衡数值集中在 `js/config.js`，改完刷新页面立即生效。
