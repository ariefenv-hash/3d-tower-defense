# 棱镜回响 · 星墨手卷 PRISM ECHO

3D Roguelike 塔防游戏 · Three.js 纯前端实现 · 零构建 / 零依赖 / 支持 PWA
**玄墨为底 · 宣纸作字 · 朱砂点印 · 月金描线** —— 桌面与手机双端可玩

## 怎么运行

**方式一（推荐，双击即玩）**：解压后直接双击 `index.html`。
Three.js 已内置于 `vendor/`，无需联网、无需服务器、无需安装任何东西。
（此模式下 PWA 自动跳过，不影响游玩。）

**方式二（本地服务器 / PWA）**：

```bash
cd prism-echo
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**手机 PWA 安装**：把目录托管到任意静态服务（GitHub Pages / Netlify / 局域网 http 服务器均可，
需 https 或 localhost），用手机浏览器打开后「添加到主屏幕」即可全屏游玩、**完全离线可玩**。

**手机（无托管）**：把解压目录发给手机后用浏览器打开 `index.html`，
即可以触屏手势游玩（见下）。

## 这是一个什么样的塔防

它不是「塔各自开火」的常规塔防。核心机制是 **光束折射**：

> 星核（基地）持续吐出一道月金色的**高能流光**——但它不瞄、不追、不回头。
> 光束总是射向最近的棱镜塔，被折射后再射向下一个棱镜，
> 由此织出一张贯穿战场的 **伤害光路**。
> **棱镜摆在哪里，光就烧穿哪里。**

围绕这个核心，再叠加两层 Roguelike 随机构筑：

1. **每局随机星图** —— 入口、蜿蜒曲径、能量格（建造 6 折）、岩石（禁建）全部程序化生成；
2. **每波肃清后三选一「回响拾遗」** —— 18 种遗物（分光棱镜 / 超导谐振腔 / 处决协议……）一次性获取、本局永久生效，配合三系塔（棱镜 / 霜塔 / 脉冲炮）形成每局不同的构筑答案；
3. **星屑残页（v1.1.1）** —— 无尽长夜后期 18 遗物拾尽后，三选一自动以 4 种可无限重拾的「星屑残页」（锋/谐/富/愈）补齐，同类残页在拾遗栏合并为一枚印匣并以 ×N 角标计数——构筑永不停摆，无尽模式不再锁死。

十五波攻防，守住星核即胜利；通关后可入「无尽长夜」。星核沉眠即重开——新星图、新构筑（Roguelike 永久死亡）。

## 双端操作

| 操作 | 桌面 | 触屏 |
|---|---|---|
| 建造 / 选中 | 左键点击（先点底部卡片选塔） | 轻点（先点卡片选塔）；**建造模式下拖动可精调放置点，抬手落子** |
| 转动视角 | 按住拖拽 | 非建造模式下单指拖动 |
| **地图缩放** | 滚轮 | **双指捏合**，或右侧 ⊕⊖ 按钮 |
| 连续建造 | Shift + 点击 | 放置后再次点卡片重新进入（或点卡片两次保持建造态） |
| 快速选塔 | 1 / 2 / 3 | 点卡片 |
| 立即开波 | Space | 点「启第 N 波」按钮 |
| 取消选择 | Esc | 点空白处 / 再点卡片 |
| 遗物详情 | 悬停左侧印匣 | 点按印匣展开 / 收起 |

移动端已按手机竖屏完整适配：HUD 两行紧凑排布、布防卡三列等分、
塔详情变全宽底板、三选一改横排信笺样式，顶部/底部自动避开刘海与 Home Indicator 安全区。
横屏短视口（手机横持）另有一档：HUD 单行化、布防栏压扁贴底，纵向空间还给战场。
支持触觉反馈（放置 / 升级 / 拾遗时轻触震动，无振动 API 的设备自动静默）。

> **为什么推荐安装 PWA 全屏**：普通移动浏览器底部有导航栏，会占掉一截视口高度。
> 本游戏已用 `100dvh` 动态视口 + 容器实测尺寸渲染，导航栏展开时界面会自动收缩到可见区内、
> 建造栏绝不会被压在栏下；但 PWA 全屏仍能带来更大的战场视野与更沉浸的体验（开局会提示一次）。

## 数值小抄

- 三系塔：**◈ 棱镜**（折射流光，增益 ×1.15→1.58）· **❄ 霜塔**（范围减速 30%→50%）· **✦ 脉冲炮**（单体弹丸）
- 光束：初始 4 段折射链，每段衰减 12%；棱镜可反向增幅
- 敌人六种：蜂群 / 游袭者 / 重装体 / **偏导体（光束抗性 45%）** / 裂生体（死亡分裂）/ 湮灭核心（Boss）
- 击杀 + 波次奖励 + 遗物利息 = 能量循环；漏怪扣星核，归零即败

## PWA 细节

- **清单** `manifest.json`：standalone 独立窗口、玄墨 `#0b0e17` 主题色、任意方向；
- **离线** `sw.js`：cache-first 策略，首发预缓存全部本地资源（24 项）+ Google Fonts 运行时缓存，
  断网后游戏照常可玩，字体自动回退本地宋体；
- **兼容**：SW 仅在 `https:` / `localhost` / `127.0.0.1` 下注册，`file://` 双击直开时静默跳过，
  三种打开方式互不干扰；
- **图标**：AI 生成水墨底图 + 思源宋体 SemiBold 朱砂方印「回」合成（192 / 512 / maskable /
  apple-touch 全套）+ 手绘矢量 `icon.svg` 作 favicon；
- 升级资源时改 `sw.js` 里的 `CACHE` 版本号即可触发自动更新。

## 性能与加载

- **卷首启动屏**：朱砂印「回」呼吸动画，脚本加载期间即时出画，启动后淡出（8s 兑底自动移除）；
- **并行加载**：全部脚本 `defer`（HTML 解析与下载并行、按序执行）+ `preload` 预拉最重的 three.min.js；
- **字体非阻塞**：Google Fonts 走 print→all 切换，先用本地宋体出画、联网字体就位后无感替换；
- **触屏手势地面**：`#app touch-action: pan-y` 拦下双击/双指页面缩放（iOS 无视 user-scalable=no 的问题一并解决），
  画布保持 `none` 全手势自管，模态内容在矮屏可纵向滚动；
- **轻点判定**：以「距按下点的净位移」判定（非累计路径），容差 16px / 750ms —— 真实手指抖动不再误判为拖拽；
- **触屏建造**：建造模式下单指拖动 = 精调放置点（幽灵跟随），抬手落子；非建造模式拖动 = 转卷；
- **动态视口**：`#app 100dvh`（100% 链兜底）+ 渲染器以容器实测尺寸重算 + `visualViewport` /
  `orientationchange` 监听 —— 移动浏览器导航栏展开收起、旋转屏幕时画布与 UI 永远贴合可见区；
- **GPU 资源零泄漏**：重开星图、塔升级/出售、敌人死亡、光路重建、建造预览切换时，
  独占的几何体与材质一律 `dispose()`（共享几何体模块级复用、不释放），长时间游玩不涨内存；
- **渲染器**：`powerPreference: high-performance` + DPR 上限 2，兼顾画质与手机帧率。

## 主题定制

- **字体**：思源宋体（题字 · 正文，500 字重题字保证「回」「响」内白清晰）· Cormorant Garamond（数字），
  由 Google Fonts 提供；离线时自动回退本地宋体，书卷气不减。
- **配色**：全部集中在 `style.css` 的 `:root` 变量（`--cinnabar` 朱砂 / `--gold` 月金 / `--paper` 宣纸 …），
  3D 场景颜色集中在 `js/config.js` 与各模块的材质定义处。
- **调参**：所有平衡数值集中在 `js/config.js`，改完刷新页面立即生效。
